# ViewAble

**AI-Powered Web Accessibility for Everyone**

ViewAble is a Chrome extension that makes web content accessible through AI-powered features including reader mode, translation, summarization, quiz generation, and natural text-to-speech.

![ViewAble Banner](https://via.placeholder.com/800x200/1a1a1a/ffffff?text=ViewAble+-+AI-Powered+Accessibility)

## 🌟 Features

### AI-Powered Tools
- **📝 AI Summarization** - Get 1-2 sentence summaries of any article using Groq AI
- **🌍 AI Translation** - Translate content into 16 languages in seconds
- **🎯 AI Quiz Generation** - Auto-generate 5 comprehension questions to test understanding
- **🔊 Natural Text-to-Speech** - Hybrid TTS using ElevenLabs premium voices + Chrome fallback with speed control

### Accessibility Features
- **📖 Reader Mode** - Clean, distraction-free reading experience
- **🔤 Dyslexic Font** - Improved readability for people with dyslexia
- **🎨 High Contrast Mode** - Better visibility for low vision users
- **📏 Text Size Control** - Adjustable font sizes (A-, A, A+)

## 🚀 Installation

### Install from Source
1. Clone this repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/ViewAble.git
   ```

2. Open Chrome and navigate to `chrome://extensions`

3. Enable **Developer mode** (toggle in top-right)

4. Click **Load unpacked**

5. Select the `ViewAble` folder

6. The extension icon will appear in your toolbar!

## 💡 How It Works

ViewAble uses a combination of AI technologies to transform web content:

- **Groq API** - Powers summarization, translation, and quiz generation
- **ElevenLabs API** - Provides natural, human-like text-to-speech
- **Smart Fallbacks** - Gracefully degrades to free alternatives when API limits are reached
- **Glassmorphism UI** - Premium, accessible user interface design
