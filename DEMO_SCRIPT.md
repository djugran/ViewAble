## PRESENTATION TIPS

### Voiceover Delivery:
- **Pace:** Conversational but confident, ~140-160 words per minute
- **Tone:** Professional yet passionate - you're solving a real problem
- **Energy:** High during demos, thoughtful during impact section
- **Emphasis:** Stress "four AI systems," user statistics, and "core infrastructure"

### Screen Recording Notes:
- **Use a clean demo website** (suggest: Medium article, BBC News, or Wikipedia)
- **Pre-test all features** to ensure smooth demo flow
- **Have backup recordings** of each feature in case of API issues
- **Show loading states briefly** (proves it's real-time, not pre-rendered)
- **Cursor movements should be deliberate** and professional

### Technical Setup:
- **1920x1080 resolution minimum**
- **Zoom into extension panel** (125-150%) for visibility
- **Hide bookmarks bar** for clean aesthetic
- **Use incognito mode** to avoid personal data
- **Test audio levels** - voiceover should be clear, demo sounds subtle
